# 树形结构表达式规则设计

## 设计方案
一个完整的 AST：
1. 逻辑节点（Logical Node）
   - operator: AND / OR / NOT
   - children: Node[]
2. 条件节点（Predicate Node）
   - field: 字段名（如 title、brand、sku）
   - operator: EQ / LIKE / STARTS_WITH / ENDS_WITH / REGEX
   - value: 匹配值

## 案例解释

```json
{
  "type": "OR",
  "children": [
    {
      "type": "AND",
      "children": [
        {
          "type": "PREDICATE",
          "field": "site",
          "operator": "EQ",
          "value": "US"
        },
        {
          "type": "PREDICATE",
          "field": "title",
          "operator": "LIKE",
          "value": "shoe"
        }
      ]
    },
    {
      "type": "AND",
      "children": [
        {
          "type": "PREDICATE",
          "field": "site",
          "operator": "EQ",
          "value": "EU"
        },
        {
          "type": "PREDICATE",
          "field": "brand",
          "operator": "EQ",
          "value": "Nike"
        },
        {
          "type": "PREDICATE",
          "field": "sku",
          "operator": "STARTS_WITH",
          "value": "NK-"
        }
      ]
    }
  ]
}
```

自然语言：
满足以下任意一种情况即可：
1️⃣ 在 US 站点，且商品标题中包含 “shoe”
或者
2️⃣ 在 EU 站点，且品牌是 Nike，并且 SKU 以 “NK-” 开头
